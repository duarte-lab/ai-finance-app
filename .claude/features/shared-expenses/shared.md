# Feature: Shared Expenses

## Objetivo
Dividir contas entre pessoas.

## Requisitos
- Cadastro de pessoas
- Associação com contas
- Percentual customizado (futuro)

## Backend
- Entidade Person
- Relação N:N com Account

## Regras
- Pessoa não pode participar duas vezes
- Soma dos percentuais = 100%

## Testes
- Divisão correta
- Validação de percentuais
