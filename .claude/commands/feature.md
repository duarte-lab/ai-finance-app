# Command: /feature

## Objetivo
Implementar uma feature completa seguindo os padrões do projeto.

## Input esperado
Nome da feature (ex: accounts, auth)

## Instruções

1. Ler:
   - .claude/features/{feature}/{feature}.md
   - .claude/context/project.md
   - .claude/workflows/feature-dev.md

2. Executar:
   - Criar entidades no Domain
   - Criar services no Application
   - Criar endpoints na API
   - Criar testes

3. Garantias:
   - Código segue Clean Architecture
   - DTOs utilizados
   - Testes criados

## Output esperado
- Código completo backend + frontend
- Testes
