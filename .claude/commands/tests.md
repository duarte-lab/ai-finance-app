# Command: /test

## Objetivo
Gerar testes automatizados para uma feature.

## Input
Nome da feature

## Instruções

1. Ler:
   - feature.md correspondente
   - código existente

2. Criar:
   - Testes unitários
   - Testes de integração

3. Validar:
   - Cobertura >= 80%
   - Casos de erro

## Output
Arquivos de teste prontos
