# Command: /full-flow

## Objetivo
Executar fluxo completo de desenvolvimento de uma feature.

## Input
Nome da feature

## Etapas

1. Implementar feature (/feature)
2. Gerar testes (/test)
3. Rodar validação
4. Aplicar refactor (/refactor)
5. Verificar segurança (/security)

## Output
Feature pronta para produção
